包内容（2026-11-13 构建，已含滚动修复）：

  src/            全部源码（React 18）

  node_modules/   全部依赖（已安装，可离线运行）

  vercel.json     Vercel 部署配置

本地运行：

  方式一（看已构建版本，无需 Node 环境之外的任何安装）：
    进入本目录，运行  npm run preview
    浏览器打开终端里显示的地址（默认 http://localhost:4173）

  方式二（开发模式，改动源码实时生效，需要 Node.js 18+）：
    npm run dev

  方式三（全新环境、没有 node_modules 时）：
    npm ci        安装依赖
    npm run build 重新构建到 dist/
    npm run preview 预览

部署：

  把 dist/ 目录整个上传到任意静态托管平台即可
  （Vercel / Netlify / Cloudflare Pages / 腾讯云 EdgeOne Pages 均可），
  或重新运行 npm run build 生成最新的 dist/。
