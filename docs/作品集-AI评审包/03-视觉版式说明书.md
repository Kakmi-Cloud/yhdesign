## 2. 逐段版式（桌面 1256×808）

### 顶栏 `sw-bar`
`position: fixed`，高 **64px**，左右内边距 `clamp(18px,4vw,60px)`；半透明底 + `backdrop-filter: blur(18px)` + 1px 细线。
三个入口：`← 返回`（min 88×44，1px 描边）、`YH / {id} — 08`（11px Mono，字距 .24em）、右侧进度条（宽 60–170px、高 2px，强调色填充）+ `INDEX {id}`（min-height 44px）。
点 `INDEX` 展开右侧抽屉：宽 `min(430px,94vw)`，8 行项目，每行 min-height 58px，两列 grid（38px 编号 + 内容），当前项目名带强调色下划线。

### 01 首屏 `sw-hero`
`min-height: 92svh`，`display:flex; align-items:flex-end`，底 `#111`，溢出隐藏。**双层同图**：
- 背景层 `sw-hero-bg`：`object-fit:cover`，`scale(1.18)`，`blur(32px) brightness(.58) saturate(1.12)` —— 用同一张图把画面铺满
- 前景层 `sw-hero-fg`：flex 居中，横图 `object-fit:cover` + `scale(1.08)`；竖版界面图（05）与 `fit:contain` 的素材改为 `width:auto; max-width:100%; object-fit:contain`，舞台内边距 `7vh 6vw 15vh`，**保证完整不裁切**
- 渐变遮罩：上 `rgba(0,0,0,.34)` → 30% 处 `.06` → 46% 透明 → 底 `.78`
- 右上超大编号：`clamp(15rem,40vw,40rem)` Oswald、白色、`opacity .14`、`right:-1.5vw; top:4vh`
- 左下文字：眉标 11px Mono 大写；`<h1>` 主标题；副标题 13px（截断 22 字）；状态徽标 11px 800 字重、强调色实底白字、padding 8×12
- 右下竖排 `SCROLL ↓`（`writing-mode: vertical-rl`，10px Mono，字距 .28em）
- 滚动视差：桌面且 >900px 且未开启减少动效时，前景 `translate3d(0, min(scrollTop*.16,150px),0) scale(1.08)`

**手机差异**：`min-height:82svh`；背景 `blur(24px) brightness(.5)`；舞台内边距 `9vh 3vw 25vh`；前景改 `object-fit:contain`、`rotate(-1.6deg) scale(1.02)` + `drop-shadow(0 22px 42px rgba(0,0,0,.45))`（相片感）；标题 `clamp(2.7rem,12.5vw,4.6rem)`；顶栏隐藏中间编号，`← 返回` 缩到 72px。

### 02 一句定位 `sw-statement`
大留白段。`grid-template-columns: 1.35fr 0.65fr`，列间距 `clamp(30px,6vw,100px)`，上下内边距 `clamp(90px,13vw,180px)` / `clamp(50px,8vw,110px)`，`align-items:end`。
左：一行定位句，`font-size: clamp(1.5rem,3.1vw,3.1rem)`、行高 1.32、800 字重、`max-width:22ch`；句前 66×5px 强调色短横线，下距 30px。
右：两个数字纵向排列（gap 26px），Oswald `clamp(3.2rem,6vw,6rem)`、行高 .9；第二个数字用强调色；数字下 11px 说明小字。
**手机**：单列，数字改横向排列，字号 `clamp(2.6rem,12vw,3.6rem)`。

### 03 错位双图 `sw-spread`
12 栏 grid。大图 `grid-column:1/9`、`aspect-ratio:16/10.5`；小图 `grid-column:8/13`（**与大图跨 8 栏重叠**）、`grid-row:1`、`align-self:end`、`margin-bottom:-11%`（越出段落底边）、`aspect-ratio:4/3`、`rotate(-2.2deg)`、8px 纸色描边、`box-shadow:0 26px 64px rgba(0,0,0,.26)`、`z-index:3`。
大图左上 `FIG. 01 / 产品` 小标签（10px Mono、纸底墨字、padding 9×11）。
hover：图片 `scale(1.05)`（0.9s 缓动）；小图旋转回 −1deg。
**手机**：改 `display:block`，大图满宽 `4/3.1`，小图宽 66%、`margin:-24% 0 0 auto`（叠压在大图下方右侧）、6px 描边。

### 04 反相全幅 `sw-invert`
整段底色翻转为反相色，形成节奏断点。上下内边距 `clamp(36px,5vw,70px)` / `clamp(48px,7vw,90px)`。
头部左右两行 10px Mono：`FUNCTIONS / 04` 与「功能均可实现」，`opacity .7`。
媒体区 `height: clamp(420px,72vh,720px)`，全幅产品图 `object-fit:cover`（contain 素材带 10% 灰底）。
4 个功能短词胶囊悬浮在图边缘：`#14161A` 实底、白字、12px 800、圆角 999px、1px 白边、微旋转；位置分别为 `top20%/left4% (−3°)`、`top28%/right5% (+2.4°)`、`bottom25%/left8% (+1.8°)`、`bottom15%/right7% (−2°)`。
左下描边巨字 `OBJECT`：`clamp(6rem,17vw,16rem)`、1px 白描边、`mix-blend-mode:difference`、`opacity .5`、`bottom:-5%`（部分出血）。
**手机**：媒体高 52vh，胶囊 10px、padding 9×11，描边字 24vw，位置左右各收缩到 3–4%。

### 05 偏栏 `sw-aside`
`min-height:88vh`，12 栏 grid，上下内边距 `clamp(90px,12vw,170px)`。
左 1–7 栏：`clamp(10rem,25vw,26rem)` Oswald 巨型描边编号（2px 墨色描边、字透明、`opacity .3`），大量留白。
右侧 8–12 栏窄图：`aspect-ratio:3/4`、`rotate(1.6deg)`、`box-shadow:-26px 30px 0 var(--sw-shadow)`（硬阴影）。
左上竖排 `DETAIL / MATERIAL / PROCESS`（10px Mono，字距 .3em，`left:4vw; top:14%`）。
左下角两行 11px 次级文字：项目出处（截断 24 字）+ 前 3 个阶段名，最大宽度 46%。
**手机**：改 block，隐藏竖排标签，描边字 42vw，窄图宽 74%、`margin:-16% 0 0 auto`（与描边字叠压），说明文字移到图下方。

### 06 横向胶片 `sw-film-wrap`
顶部 1px 细线；头部 `IMAGE ARCHIVE / 09 FRAMES` 与 `DRAG ↔`（10px Mono）。
`display:flex; overflow-x:auto`，隐藏滚动条，可鼠标拖动 / 触摸横滑。5 帧高度统一 `clamp(260px,44vh,430px)`，但**宽度与上下位置刻意不等**：30vw(−1.2°) / 44vw(+38px) / 26vw(+1.4°) / 38vw(+20px) / 30vw(−0.8°)；gap `clamp(14px,2vw,28px)`。
hover：图片 `scale(1.06)`，倾斜帧旋正。
**手机**：帧高 34vh，宽 62/76/54/70/60vw，上移量 0/22/0/14/0px，gap 14px。

### 07 收尾 `sw-outro`
2 栏 grid，1px 顶线。首行 `进展` 小标 + 大号状态全称（`clamp(1.2rem,2.4vw,2.2rem)` 800）。03 项目额外一行 12px 小字「孔雀石系列已开始落地 · 其余形态或细节尚未确认」。
细线下方两个 11px 次级文字：统一功能可行性口径 + 资料来源（最多 3 条 label）。
`← 返回作品集` 按钮 min-height 48px、1px 描边。
**手机**：单列，状态 1.35rem。

### 08 下一项目预告 `sw-next`
`height:min(62vh,560px)`，整块可点。全幅下一项目主视觉，`brightness(.6) saturate(.92)`；hover 图片 `scale(1.06)`、提亮到 .7。
左下文字：`NEXT PROJECT / {id}`（10px Mono）、项目名 `clamp(2.4rem,7vw,6.6rem)` 900、右侧 `→` `clamp(2rem,5vw,4rem)`。
**手机**：高 46vh，标题 `clamp(2rem,10vw,3.4rem)`。

## 4. 交互清单（评分方无法点击，此处如实列出实现行为）

| 交互 | 实现 |
|---|---|
| 打开板块 | 点击首页项目卡片 / 列表行，或深链 `?plain=0#p={01..08}`；浮层从右侧推入，锁定底层页面滚动 |
| 返回 | 顶栏 `← 返回`、页脚 `← 返回作品集`；关闭浮层 |
| 切换项目 | 顶栏 `INDEX` 展开 8 行抽屉；底部全幅预告跳下一个项目；切换后回到顶部并收起索引 |
| 滚动 | 浮层内部滚动；顶栏 2px 进度条随滚动填充；首屏前景视差位移（上限 150px） |
| 入场揭示 | `IntersectionObserver`，`data-reveal` 元素由 `opacity:0 / translateY(34px)` 过渡到可见，只触发一次 |
| 跟随光标 | 精确指针设备显示 72px 圆形 `VIEW` 光标，`mix-blend-mode:difference`；悬停图片/胶片时放大到 100px；触摸设备隐藏 |
| 横向胶片 | 鼠标按住拖动改变 `scrollLeft`；触摸端原生横滑 |
| 图片 hover | `scale(1.05~1.06)`，0.8–0.9s `cubic-bezier(.16,1,.3,1)` |
| 减少动效 | `prefers-reduced-motion: reduce` 时：揭示元素强制可见、所有 `animation:none` / `transition-duration:.01ms`、前景视差关闭、光标隐藏 |

## 5. 图像取用规则（与「以产品为主体」直接相关）

1. 每个项目拼出 10 张图序列：资料层主视觉 → 资料层补图 → 项目原有图集，按最终 URL 去重。
2. 主视觉恒为第 0 张；其余按 alt 关键词稳定排序：**「细节/特写/产品/发光/主视觉/结构/效果/造型/渲染/成品」优先（+1）**，「场景/人物/使用/展板/过程/调研/分镜/旅程/灵感/概念板/空间/包装/示意/草图」后置（−1）。
3. 主视觉段（首屏、03、04、05 段）额外排除过程图：alt 含「草图/线稿/手绘/推演/过程/分镜/旅程/灵感/概念板/示意/三视图」或文件名 `diemu-01` / `fig20` / `sketch` 的图，只留在第 06 段胶片档案里。此规则来自素材核查：`diemu-01.webp` 实为线稿、`fig20.webp` 实为制作过程图，原 alt 未写明。
4. 05 项目（竖版手机界面图）与 `fit:contain` 素材双端 `object-fit:contain`，完整不裁切；其余横图桌面 `cover`、手机 `contain`。
5. 未新增任何产品图片，全部为作品集原有素材。

## 6. 已知限制与未取证项（请勿据此推断）

- 未做真机手势、帧率、弱网节流、读屏器与纯键盘走查；上述 CSS 行为是桌面无头 Chrome 下的实现与计算样式。
- 字体为 Google Fonts 外链，离线打开会回退系统字体，字宽与观感与在线状态略有差异；`A-展示板块-完整视觉版.html` 保留了外链。
- 03 项目评审表上的外观型号与完成日期为手写字迹，存在辨识不确定性，页面不引用为确定参数。
- 06 段胶片的横向拖动在静态截图 / PDF 中不可操作，实拍截图只显示首屏可见的若干帧。
- 本说明书描述的是「改版后的项目展示板块」；更早的「项目文件档案版」与「最初的多套独立详情页」不在评分对象内。
