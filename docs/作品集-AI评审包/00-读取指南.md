# 00 · 读取指南（先读这份）

这是给 **Gemini 等无法操作网站的 AI** 准备的「作品集项目展示板块」独立评审包。  
原作品集是 React 交互网页，需要启动本地服务、点击项目卡片才能进入详情页；本包把它**冻结成静态材料**，不需要服务器、不需要构建、不需要点击，解压后即可读取。

> 生成时间：2026-11-12　｜　评分对象：改版后的「项目展示板块」（8 个项目，桌面 + 手机）  
> 本包**不含任何既有评分结论**，以保证评审独立。



---

## 一、怎么交给 Gemini（三选一）

| 方式                    | 上传哪些                                                        | 适用                                        |
| --------------------- | ----------------------------------------------------------- | ----------------------------------------- |
| **A · 只传 2 个文件（最推荐）** | `E-必读三合一.md` + `C-展示板块-图文长页.pdf`                            | 平台上传文件数有限；前者含评分指令+逐字文案+版式数值，后者含 8 个项目完整图文 |
| **B · 标准**            | `01` + `02` + `03` + `C` PDF（可再加 `D` PDF 或 `06-视觉证据/` 首屏截图） | 通用，材料分工清晰                                 |
| **C · 最完整**           | 解压后上传整个 `作品集-AI评审包/` 文件夹，或直接上传根目录 zip                       | 平台支持多文件 / 文件夹上传；AI 可自行索引                  |
| **D · 纯文本优先**         | `E-必读三合一.md` + `04` + `B-展示板块-纯内容版.html`                    | 平台只收文本、不支持图片；纯内容版每图都有中文说明，可据此评版式          |

**无论哪种方式，评分指令都必须在材料里**：A / D 方案的 `E-必读三合一.md` 已完整包含 `01-评分任务书.md`；B / C 方案请单独附上 `01`。也可直接复制 `01` 第九节的提问。它写明了评审边界、禁止臆测条款与输出格式。

**补充视觉证据**：若平台允许上传图片，建议再附 `06-视觉证据/` 中 `D01-01`、`D03-01`、`D05-01`、`D07-01`、`D08-01`（桌面首屏，覆盖浅色 / 深色 / 竖版界面三种典型情况）与 `M01-01`、`M03-01`、`M05-01`（手机首屏）；想看完整节奏则按 `D01-01`→`D01-08`、`M01-01`→`M01-08` 连看。或者干脆直接上传 `D-视觉证据合订.pdf`（128 页，7.7MB）。

## 三、三条关键提醒

1. **`02` 才是页面文字，`04` 不是。** 改版大幅削减了说明文字，页面只显示编号、项目名、一句定位、4 个功能短词、2 个数字、状态与出处。`04` 是后台资料层全文，用来核查文案有没有依据，**不能拿来算页面文字量**。任务书第七节第 1 条专门写了这一点。
2. **看不到 ≠ 不存在。** 静态材料无法点击，交互行为逐条写在 `03` 第 4 节（INDEX 切换、进度条、视差、入场揭示、跟随光标、胶片拖动、hover、减少动效降级）。
3. **截图编号即坐标。** `D01-04` = 桌面 · 01 项目 · 第 04 段（反相全幅）；`M03-01` = 手机 · 03 项目 · 首屏。完整对照见 `06-截图索引.md`。

## 四、离线使用的注意事项

- `A` 保留了 Google Fonts 外链；完全离线时字体会回退到系统字体，字宽与截图略有差异。以 `06-视觉证据/` 的真实截图和 `C` PDF 为准。
- `A` / `B` 用相对路径引用 `assets/`，**请保持目录结构，不要单独挪走 HTML 文件**；`C` / `D` 两个 PDF 是自包含的，可单独上传。
- PDF 由浏览器打印生成，固定定位、混合模式与分页处的表现可能与在线渲染略有差异。
