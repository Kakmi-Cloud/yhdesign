# YHDesign 作品集 · 成果文档索引

本目录保存与网站一同交付的全部过程文档与证据（网站源码在 `src/`，素材在 `public/`）。

| 文件 | 内容 |
|---|---|
| `portfolio-review.html` | 专业评审报告（配 `review-assets/` 截图） |
| `项目展示板块-改版.html` | 项目展示板块改版对照（引用 `../public/` 素材） |
| `项目文件-统一排版.html` / `项目文件-统一结构与文案.md` | 项目文件重排版与统一文案口径 |
| `作品集-8页重构-素材与结构说明.html/.md` | 8 个独立项目页的素材与结构说明（配 `8页重构证据/`） |
| `作品集改造-反馈对照.html/.md` | 依评审反馈逐项改造的对照表（配 `改版证据/`） |
| `作品集-AI评审包/` | 给 AI 评审用的静态快照包（含源码、视觉证据与素材） |
| `handoff/` | 交付时的手机端改造指令、进度与目标 |

> 说明：部署上线的是 `dist/` 构建产物（由 `src/` + `public/` 生成）；本目录为审阅/归档材料，不参与构建。
> 两个 `*.zip` 评审压缩包为上述内容的可再生打包副本，未重复入库。
