## 三、技术硬约束（会被自动核验，违反即打回）

1. 所有改动**必须包在 `@media (max-width: 1023px)` 内**，桌面端（>1023px）零回退。
   桌面基线：视口 1256×808 → `documentElement.scrollHeight = 6277`、`scrollWidth = 1256`、`.os-desktop-root` 存在、无 `.ms-overlay`、`.detail-fold` 数量 0。改前改后必须一致。
2. 正文 **≥15px**；触控目标 **≥44×44**；**无横向溢出**（414 视口下 `scrollWidth ≤ 414`）。
3. 产品本体图**不得裁切/变形/加滤镜**：产品主图必须 `object-fit: contain`（禁 `object-cover`），不得修改图片文件本身。
4. 动效必须尊重 `prefers-reduced-motion: reduce`（关闭位移/缩放，仅保留透明度）。
5. 只改 CSS / JSX；**不引入第三方库、不引入外链字体**。
6. 不用行号定位；每处补丁给出**足够唯一**的上下文片段。
