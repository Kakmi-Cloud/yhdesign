## 二、六大维度逐项：调整 → 动画场景 → 表达意图

### 1. 整体兼具高级感与趣味性（原判定：基本符合；扣分：跨项目机械套用）
- **调整**：抽出 `SEQUENCES` 按品类换序（7 种节奏）；每项目一套英文标签（05 UI 用 `INTERFACE / FLOW / SYSTEM / INTERACTION`，08 用 `CHARACTER / STATE / EXPRESSION / MERCH`）；每项目一个专属互动装置。三色令牌与极小面积强调色规则保留。
- **动画场景**：转场蓝图幕布 + 三片快门；INDEX 3D 抽屉扇入 + 磁吸；8 种品类专有装置。
- **表达意图**：让「反套路」落在结构而不是通用旋转角度上；不同品类的作品不该共用一套花活。

### 2. 排版简洁而内容充实（原判定：不符合）
- **调整**：02 段无问卷数据项目改用 `project.specs` 真实规格摘录；03 段把 `alt` 渲染成可见图注；04 段 hover 展开真实功能机制；05 段换成四面 3D 标本盒（材质 / 结构 / 工艺 / 边界）+ 左栏 60–100 字设计推导；首屏补完整副标题与两条数据。
- **动画场景**：逐字重组定位句、解剖滑杆双图注、引线热区展开、3D 标本盒、翻牌胶片背面图注。
- **表达意图**：信息不以段落形式堆回来，而是附在产品上、藏在可玩动作里——想看细节就拖、想读图注就翻、想看参数就转盒子。

### 3. 画面与文字有机融合（原判定：部分符合）
- **调整**：03 段改成成品 / 细节解剖滑杆，两侧可见图注；04 段胶囊改为 SVG 引线指向产品四个锚点，激活时描线生长；品类标签动态映射；`qimu-01` / `diemu-01` 经图像核查为线稿，按文件名排除出主视觉段，只留在胶片档案。
- **动画场景**：分割线拖动、引线 `stroke-dashoffset` 生长、取样放大镜（仅在产品首屏出现，滚出即收起）。
- **表达意图**：文字真的指向画面里的部位，而不是飘在四角；取样器不遮挡后文说明。

### 4. 图文比例协调（原判定：不符合）
- **调整**：首屏高度下调并补信息带；正文 15–16px、说明 14px、图注 13px、胶囊 14px（手机 13px）；装饰巨字收敛；建立「巨型标题 → 定位大字 → 14–16px 说明 → 12px 英文标签」四级字阶。
- **动画场景**：首屏光圈揭示；顶栏游标卡尺刻度随滚动填充。
- **表达意图**：保留大图冲击力，但让读字不吃力；装饰字退到背景，不与正文争面积。

### 5. 留白适度不削弱信息密度（原判定：不符合）
- **调整**：删掉 05 段整屏描边巨字，换成 3/4 视角四面 3D 标本盒（每面嵌产品图与真实参数）；02 段改跨列双栏，左正文右数据 / 规格摘录，6 个无问卷数据项目不再空栏。
- **动画场景**：标本盒拖拽旋转与面跳转；02 段逐字揭示。
- **表达意图**：留白仍是疏密节奏，但不再空着——转动盒子这件事本身把材质、结构、工艺与资料边界一并交代完。

### 6. 表达贴切克制（原判定：部分符合）
- **调整**：移除全部 22 / 24 字硬截断，03 副标题为完整句「实习期间完成的灯具设计：材质探索与 AI 形态推演」；03 数字栏由「打样 / 评审结果勾选」改为 `2 张外观造型评审表` 与 `3000K LED 灯板色温`；资料行去掉「资料：现有资料」同义反复，03 改为「外观评审表（台灯 / 客厅吊灯）· AI 形态方案」；全页「功能均可实现」只保留 1 次；胶片帧数标注改为实际渲染数 05。
- **动画场景**：卷帘式下一项目预告、翻牌背面图注。
- **表达意图**：只写资料确认过的东西；用括号表达从属，避免同级圆点造成并列歧义。

## 四、动画清单（场景 / 形式 / 语境 / 意图）

原则：每个动画只在对应语境出现一次，不做全局装饰堆积；全部支持 `prefers-reduced-motion` 降级。

| 场景 | 形式 | 语境 | 表达意图 |
| --- | --- | --- | --- |
| 转场 | 蓝图网格幕布 + 三片快门反向揭膜，切项目 / 深链进入时播放一次 | 03 工程图纸主题延伸 | 把「换项目」做成打开另一份档案；`App.jsx` 按项目 id 加 key 触发重挂载 |
| 导航 | INDEX 抽屉 3D 扇入、8 行逐行 `rotateX` 错位、悬停磁吸位移 | 标本抽屉 | 索引本身可玩 |
| 首屏 | 光圈 `clip-path: circle()` 揭示 + 双层同图视差 + 132px 取样放大镜（十字线 + 260% 局部放大） | 灯具 / 材质取样 | 用设计师看细节的动作开场；滚出首屏即收起 |
| 定位句 | 逐字 `rotateX` 重组，静止后完全可读 | 02 段 | 一句话也有被拆解的节奏，不牺牲阅读 |
| 品类装置（8 种） | 01 明暗推杆 / 02 进度轨道 / 03 图纸游标 / 04 推入木楔开关 / 05 流程节点 / 06 软包拆解 / 07 六向罗盘 / 08 温度轴 | 各项目核心机制 | 把「功能可实现」从声明变成可亲手试的动作；参数全部取自已有资料（08 的 −18°C — +38°C、03 的 450 / Ø1000 / 2.5mm） |
| 成品 / 细节 | 可拖解剖滑杆，两图 `clip-path: inset()` 对照，两侧可见图注 | 产品整体与局部 | 把 `alt` 里的说明搬到版面，图与字互相指认 |
| 可实现功能 | SVG 引线 `stroke-dashoffset` 生长，hover / 点按展开真实机制说明 | 图纸引线 / 卡尺 | 取代硬编码四角胶囊，功能词锚定到产品部位 |
| 结构与材质 | CSS 3D 四面标本盒：拖拽旋转、面标签跳转、初始 3/4 视角、每面嵌产品图 | 网页内建模展示，不引入 3D 引擎 | 用转动盒子替代整屏空白，同时装入四类信息；轻量可离线可读屏 |
| 图像档案 | 5 帧不等宽错落胶片 + 点击 `rotateY` 翻牌，背面是中文图注 | 相片背面写字 | 图注不缺失也不铺成文字墙 |
| 下一项目 | 锯齿撕纸卷帘 `clip-path: polygon()`，hover 掀开亮图 | 翻到下一件作品 | 收尾记忆点，动作而非链接 |
| 全局进度 | 顶栏 3px 进度条 + 游标卡尺刻度随滚动填充 | 工程测量 | 阅读进度与工程语境一致，只占极小面积 |

## 六、验证结果

- **18/18 场景**：桌面 8 项目 + 2 组完整 9 段序列 + 手机 8 项目，全部渲染成功，运行时 JS 异常 0。
- **0 坏图 / 0 横向溢出**：每页 23–36 张图全部加载；`scrollWidth = clientWidth`（桌面 1241 / 手机 414）；小于 44px 的可点击控件 0。
- **交互闭环实测**：翻牌（`is-flipped=true`，背面图注「夜间发光效果」）、立方体面跳转（active 2 / `rotateY(-196deg)`）、解剖滑杆（clip 20% / handle 80%）、引线热区（`paths=1`，展开「人体感应自动开灯…」）、明暗推杆、INDEX 抽屉 8 行、切换项目转场幕布出现并 1.2s 后收起、切到 03 后顺序变为 engineering 且标签变为 `ENGINEERING`。
- **降级达标**：`prefers-reduced-motion` 下动画数 0、幕布不渲染、揭示元素全部可见、光圈 `clip-path: none`。
- **四条口径全部保留**：01「毕业设计 · 已落地」、03「已进入打样落地阶段」、03「孔雀石系列已开始落地 · 其余形态或细节尚未确认」、全站「作品集内所有项目所述功能均可实现」（全页仅 1 处）。
